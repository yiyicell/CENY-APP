# Ceny App - Control de Gastos Personales

Proyecto de Ingeniería de Software II enfocado en ayudar a los usuarios a llevar el control de sus ingresos y gastos personales, sugiriendo un mejor uso del dinero basado en la regla 50/30/20 y gestionando metas de ahorro.

## Estado Actual del Proyecto: Fase de Diseño y Arquitectura

Actualmente, el proyecto se encuentra en la fase de definición arquitectónica y configuración del entorno de trabajo bajo la metodología Scrum.

## Arquitectura Definida (3 Capas - MVC)

El sistema operará bajo una Arquitectura de 3 Capas orientada a API:

1. **Capa de Presentación (Frontend / Vista):** React / Expo.
2. **Capa de Lógica de Negocio (Backend API / Controlador):** Python con FastAPI.
3. **Capa de Acceso a Datos (Base de Datos / Modelo):** PostgreSQL (Supabase) cifrado por el puerto 443.

## Estructura del Repositorio

- `/Diagramas` - Contiene los modelos de arquitectura, flujos de datos y diseño del sistema.
- *(Próximamente)* `/frontend` - Código fuente de la aplicación móvil.
- *(Próximamente)* `/backend` - Controladores, lógica de negocio y acceso a datos.
